# CTA Frequent Network — ridership analysis

Does the CTA's 2025 "Frequent Network" rollout (10-minute-or-better headways on 20 bus
routes) show up as a ridership gain, beyond what those routes would have gained anyway?

## Status: in progress, unverified

This analysis was largely produced by an AI coding agent in a strongly guided vibe coding session (`analyze.py`, `inference_proto.py`,
and `frequent_network_analysis.ipynb` were agent-generated). The numbers and conclusions
in the notebook — including the headline effect sizes and p-values — have **not** been
independently checked and should be treated skeptically until reviewed line by line. Known
open issues are listed under "Confounders — tested vs. not" at the end of the notebook;
there may be others.

## Data

`data/cta_bus_daily.csv` is **not** committed to this repo (see `.gitignore`) — it's a
47MB pull from a public source and can be regenerated:

- Source: [CTA Ridership – Bus Routes – Daily Totals by Route](https://data.cityofchicago.org/Transportation/CTA-Ridership-Bus-Routes-Daily-Totals-by-Route/jyb9-n7fm/about_data)
  (Chicago Data Portal, dataset `jyb9-n7fm`)
- Pulled via the Socrata API: `https://data.cityofchicago.org/resource/jyb9-n7fm.csv`
- Expected columns: `route`, `date`, `daytype` (`W`=weekday, `A`=Saturday, `U`=Sunday/holiday), `rides`
- Save the pull to `data/cta_bus_daily.csv` before running anything below.

## Layout

- `analyze.py` — route-level difference-in-differences analysis (Jan–May year-over-year,
  Frequent vs. control routes); writes `output/aggregate_change.csv` and
  `output/per_route_change.csv`.
- `inference_proto.py` — corridor-level inference prototype (permutation test, bootstrap
  CI, dose-response check) feeding into the notebook's inference section.
- `build_notebook.py` — generates `frequent_network_analysis.ipynb` programmatically.
- `frequent_network_analysis.ipynb` — the full writeup: design, seasonality checks,
  corridor-vs-route screen, parallel-trends/placebo test, corridor detail, dose-response,
  and inference. Start here.
- `output/` — CSV summaries and figures (`output/figs/`) generated by `analyze.py`.

## Running

```
python analyze.py              # route-level DiD, writes output/*.csv
python build_notebook.py       # regenerates the .ipynb from source
```

Requires `pandas`, `numpy`, `scipy`, `nbformat` (no pinned versions yet).
